# Insurance Management Project Rules

This project is a full-stack insurance company management system.

Default stack:
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: FastAPI
- Database: PostgreSQL
- AI: RAG chatbot
- DevOps: Docker Compose

Main roles:
- ADMIN
- EMPLOYEE
- CUSTOMER

Main modules:
- Auth and role-based access
- Insurance package management
- Insurance process management
- Customer management
- Employee management
- Customer assignment
- Insurance subscriptions
- Claims/incidents
- Chat
- Appointments
- Dashboards
- Login history and activity logs
- PDF-based RAG chatbot

Coding rules:
- Use clean architecture
- Keep business logic in services
- Keep database queries in repositories
- Use Pydantic schemas
- Use SQLAlchemy models
- Use JWT authentication
- Protect routes by role
- Do not hardcode secrets
- Add .env.example
- Add README instructions
